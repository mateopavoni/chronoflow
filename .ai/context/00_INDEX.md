# ChronoFlow — índice de contexto (.ai)

(2026-10-08); **INFERENCE** = deducido, no verificado.

| Archivo | Contenido |
|---|---|
| PROJECT.md | Qué es, stack, estado (archivado) |
| ARCHITECTURE.md | Componentes, flujo de datos, engine |
| DOMAIN.md | Modelo de dominio y nodos |
| CONVENTIONS.md | Cómo correr, testear, commitear |
| DECISIONS.md | Decisiones técnicas y su porqué |
| CURRENT_STATE.md | Qué funciona hoy, verificación |
| KNOWN_ISSUES.md | Limitaciones conocidas |
| OPEN_QUESTIONS.md | Preguntas abiertas |
| ROADMAP.md | Siguientes pasos si se retoma |

Fuente de verdad extensa: `/ARCHITECTURE.md` y `/README.md` del repo.
